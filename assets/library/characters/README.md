# Character animation index

The base characters are **1 Biker**, **2 Punk**, and **3 Cyborg**. Their additional
animation sets are spread across several original packs. These links work from
both the external source collection and the project library.

| Animation family | Location |
| --- | --- |
| Base movement, attacks, hurt and death | [Biker](<1 Biker>), [Punk](<2 Punk>), [Cyborg](<3 Cyborg>) |
| Extra movement, expressions and interactions | [animations](animations): folders `1`, `2`, `3` match Biker, Punk, Cyborg. Includes dash, fall, hang, pull-up, sit, talk, use, walk and walking attacks. |
| Drone interaction | `animations/{1,2,3}/Drone_interaction.png`; original sheets are in [the drone pack](<../vehicles/drones/2 Character animations>). See `Drone_pack_source.txt`. |
| Gun body poses and movement, set 1 | [guns_pack_1 / 1 Characters](<../weapons/guns_pack_1/1 Characters>) |
| Gun body poses and movement, set 2 | [guns_pack_2 / 1 Characters](<../weapons/guns_pack_2/1 Characters>) |
| Weapon grips / hands | Each gun pack's `3 Hands` folder. Match these to the same pack and character as the chosen body/weapon sheets. |
| Melee weapon poses | [beginner weapons / 1 Characters](<../weapons/beginner weapons/1 Characters>) |
| Entering doors and rappelling | [doors_and_portals / 3 Characters](<../environment/structures/doors_and_portals/3 Characters>) |

Inspect the actual sheet before selecting a frame layout or animation timing.
Do not assume similar filenames in different packs are interchangeable.
For an existing player feature, check its production art and source manifest.
The older project catalog folder `weapons/guns` mixes sheets from both gun packs;
keep existing references stable and use the separately named packs for new work.

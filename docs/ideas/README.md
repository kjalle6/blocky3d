# Ideas for later

A place to keep exploratory gameplay possibilities. If an idea becomes part
of a near-term encounter proposal, the level roadmap records that connection;
the note distinguishes the proposed prototype from its later extensions.

- [Breakable supply crates](BREAKABLE_SUPPLY_CRATES.md) — investigate crates
  as destructible cover in the Level 3 tank encounter. Releasing supplies is
  still a later extension using existing loot systems.
- [Parkour, shooting, and cover](PARKOUR_SHOOTING_AND_COVER.md) — use double
  jumps, wall jumps, and routes above or below enemies to find exposed firing
  angles around their cover. A possible fit for tall vertical levels with a
  choice of approach, rather than every shootout.
